How to use it

  1. Write as you go. A meal remembered the next day is a guess.
  2. 0 is fine, 1 a little, 2 uncomfortable, 3 bad. Use the same scale every day.
  3. If you were fine, say so. A blank box is not a good day, it is an unknown one.
  4. After two weeks, pick one question and count both sides.
