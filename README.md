# Tumlii landing page

The public landing page for Tumlii, a gentle tummy diary: `index.html` (waitlist, features, FAQ) and `signup.html`.

- Plain static HTML and CSS, no build step. Open `index.html` in a browser, or serve the folder with any static host.
- The waitlist and sign-up forms are front-end only for now: they check the input and say plainly that nothing is sent.
  Set `WAITLIST_ENDPOINT` (index.html) and `SIGNUP_ENDPOINT` (signup.html) when a service is chosen.
- `assets/screens/` holds real app screenshots with example data, shown in the "See it on your phone" section.
- Early release: Android in December 2026, iPhone in January 2027.

The page is maintained in the app repository (`apps/landing`) and copied here for hosting.
